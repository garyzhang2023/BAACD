
# S5 Sealed Coder-1 Record

`S5_coder1_sealed_record.csv` contains the first coder's judgments for the same 130 anonymous Q-IDs used in S4. `S5_method_appendix.md` documents the agreement metrics, low-prevalence rule, and supporting checks. The Q-ID-to-original-record mapping is withheld because it can reconnect the blind reliability records to the source dataset.
