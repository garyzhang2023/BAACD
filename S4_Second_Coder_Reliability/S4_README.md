
# S4 Second-Coder Reliability Materials

This folder contains the instructions and coding manual issued to the second coder, the anonymous returned judgments, the reported reliability results, and the analysis script. The second coder independently classified a stratified random subsample of 130 postings.

The privacy-safe upload omits the blank/original coding workbooks and adjudication excerpts because they contain job titles, skill tags, or description fragments derived from raw postings. These omissions do not affect reproduction of the reported agreement statistics. Run `Scripts/S4_reliability_kappa_ac1_pabak.py` with the included coder-2 file and the S5 sealed coder-1 record.
